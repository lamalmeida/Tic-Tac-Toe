# Tic-Tac-Toe

A small Python/Tkinter implementation of Tic-Tac-Toe with two computer opponents.

- **Level 1** uses a simple rule-based strategy and can be beaten.
- **Level 2** uses minimax and plays optimally.

This was an early game-AI project and predates the later C++ Connect Four and chess-engine projects.

## Run

Python includes Tkinter on many standard installations.

```bash
python tictactoe.py
```

Choose a difficulty level from the opening window and click a square to make a move.

## Implementation

The project demonstrates:
- a desktop GUI with Tkinter,
- board-state evaluation,
- rule-based move selection, and
- recursive minimax search.
